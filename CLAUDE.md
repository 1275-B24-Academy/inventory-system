# CLAUDE.md

Repo đào tạo thực tập sinh (TTS). Tuân theo quy ước trong @CONTRIBUTING.md, đặc biệt phần **Ngôn ngữ**:

- Code, commit message, PR title: English (commit/PR title dùng English cơ bản, theo Conventional Commits).
- Comment, PR description, issue, docs: tiếng Việt cho TTS dễ hiểu.
- Thuật ngữ chuyên ngành giữ nguyên tiếng Anh, không dịch sang tiếng Việt.
